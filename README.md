1. Đọc `docs/PHAN_TICH_BA_DU_AN.md` để xem phân tích chi tiết.
2. Mở thư mục `overleaf/`, tải hai tệp `main.tex` và `references.bib` lên một project Overleaf mới.
3. Chọn trình biên dịch pdfLaTeX và biên dịch `main.tex`.
4. Đọc `CONTRIBUTING.md` nếu muốn đề xuất chỉnh sửa.
